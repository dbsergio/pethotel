# MYPET Audio Credits

This file lists the audio assets used in MYPET, their sources, and their licenses. Todas las referencias a placeholders (.wav) han sido eliminadas; el proyecto solo utiliza archivos `.ogg` y `.mp3` reales.

### Background Music
- **bgm_nursery.mp3**
  - **Original Name:** Calm Loop
  - **Author:** wipics
  - **Source:** OpenGameArt ([Link](https://opengameart.org/content/calm-loop))
  - **License:** CC0 (Public Domain)
  - **Usage:** Nursery background music

### User Interface Sounds (Kenney UI Audio)
Estos sonidos proceden del pack "UI Audio" de Kenney.
- **Source:** Kenney ([Link](https://kenney.nl/assets/ui-audio))
- **License:** Creative Commons CC0
- **ui_tap.ogg** (Original: `Audio/click1.ogg`) - Clic simple en UI.
- **ui_select.ogg** (Original: `Audio/click2.ogg`) - Selección de elemento.
- **ui_open.ogg** (Original: `Audio/rollover2.ogg`) - Apertura de paneles.
- **ui_close.ogg** (Original: `Audio/rollover1.ogg`) - Cierre de paneles.
- **ui_error.ogg** (Original: `Audio/switch1.ogg`) - Acción bloqueada / error.
